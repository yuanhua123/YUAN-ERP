## 介绍

**（Yuan-Erp）** 是一套面向中小企业仓管场景的**进销存 / 库存管理**系统，
覆盖「基础资料 → 单据 → 库存流水 → 报表」的完整闭环。


### 它解决什么问题



### 功能一览

- **基础资料**：货物、仓库、进出类别、往来单位、工作人员、分类字典、计量单位、期初库存
- **单据管理**：入库单、出库单、调拨单、盘点单、采购/销售订单、采购/销售退货、付款单、收款单、组装单、拆卸单
  —— 录入 / 保存 / 审核 / 反审 / 作废 / 回收站恢复，全流程状态机管控
- **报表查询**：库存表、进销存、进出汇总、进出明细、利润分析、借还统计、库存预警、首页看板
- **系统管理**：参数中心（含分级覆盖与变更历史）、用户管理、角色管理、权限赋值、
  审计日志、登录日志、期间关账
- **批量能力**：各类基础资料 Excel 模板导入/导出、库位批量生成与复制、
  销售订单 Excel 批量导入、货物资料批量修改、单据列表导出
- **打印**：自研打印引擎，支持针式打印机（多联）、自由画布模板设计、Excel / PDF 导出

## 软件架构

> 本节只说明**技术选型与部署形态**，不涉及源代码结构。

### 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 + TypeScript + Vite 5 + Element Plus + Pinia + ECharts |
| 后端 | ASP.NET Core 8（`net8.0-windows`）+ Entity Framework Core 8 + Npgsql |
| 数据库 | PostgreSQL 16.4（**便携版，随包分发，无需安装**） |
| 鉴权 | JWT + bcrypt；权限码沿用原系统的 KuAuth 编码体系 |
| 交付形态 | Windows x64 桌面程序，**WinExe 托盘模式**（无控制台窗口、不占任务栏） |

### 部署形态（重点）

本系统是**「自带一切」的单机应用**：

```
双击 Yuan-Erp.exe
   ├─ 1. 定位/启动内置 PostgreSQL（便携版）
   ├─ 2. 首次运行：initdb → 建库 → 建表 → 灌种子数据（幂等，第二次跳过）
   ├─ 3. 执行幂等增量迁移（每次启动都跑，老库升级不掉数据）
   ├─ 4. 启动 Web 服务（默认端口 5076）
   ├─ 5. 自动打开浏览器
   └─ 6. 右下角托盘出现图标
```

**前端页面已经打包进 `wwwroot`，与后端同源同端口**，不需要单独部署 Web 服务器。



### 关键设计取向

- **流水账是唯一明细源**：所有库存变动写一条流水，报表从流水聚合，不建预计算的报表表。
- **审核才生效**：单据只有「审核」后才产生库存/往来流水；未审核的只是草稿。
- **反向冲销，不删流水**：反审写反向流水冲销，原流水永久保留，可追溯。
- **参数中心 + 策略模式**：五条核心业务规则（负库存、成本法、编辑策略、盘点差异、调拨记账）
  全部可配置，且支持按货物 / 仓库 / 分类 / 单据类型**分级覆盖**。
- **数据安全**：数据库 `fsync` / `synchronous_commit` / `full_page_writes` 全开，
  点「保存」即强制落盘；断电不会损坏数据，也不会出现半截数据。

### 五、升级到新版本

1. 右键托盘图标 → **退出系统**
2. 用新版的 `Yuan-Erp.exe` 与 `wwwroot\` 覆盖 `发布\` 目录

升级不会丢数据：程序启动时会自动执行幂等增量迁移，给老库补齐新增的列与索引。

> 升级后第一次打开可能提示「登录已失效」，**重新登录一次即可** ——
> 新版给登录令牌加了版本号，改密码 / 登出 / 改权限都会让旧令牌立即作废。

## 使用说明

### 界面导览

| 菜单 | 能做什么 |
|---|---|
| **首页看板** | 库存总额、本月出入库、毛利、库存预警、近 30 天走势 |
| **基础资料** | 货物 / 仓库 / 进出类别 / 往来单位 / 人员 / 分类 / 单位 / 期初库存 |
| **单据管理** | 各类单据的录入、审核、反审、作废、回收站、批量导入导出 |
| **报表查询** | 库存表、进销存、进出汇总、进出明细、利润分析、借还统计、库存预警 |
| **系统设置** | 参数中心、参数变更历史、用户 / 角色 / 权限、审计日志、登录日志、期间关账 |

### 日常操作流程

```
1. 基础资料 → 先把仓库、货物、往来单位维护好
2. 基础资料 → 期初库存 → 录入开账时的库存
3. 单据管理 → 入库单 / 出库单 → 录入 → 保存 → 审核
4. 报表查询 → 库存表 / 进销存 → 核对数量金额
```

> **关键**：单据只有**审核**之后才会产生库存流水、影响库存和报表。
> 没审核的单据只是草稿，不会动库存。

### 参数中心（重点）

原系统这五条规则写死在 VBA 里，现在都是可配置项，**改完立即生效**并自动留变更记录：

| 规则 | 可选值 | 出厂默认 |
|---|---|---|
| ① 库存不足时 | 禁止出库 / 允许但警告 / 允许负库存 | **禁止出库** |
| ② 成本核算 | 先进先出 / 移动加权平均 / 固定成本单价 / 分批实际成本 | **先进先出** |
| ③ 单据修改 | 审核后锁定 / 自由修改 / 保留版本 | **审核后锁定** |
| ④ 盘点差异 | 自动调整库存 / 只记录不调整 / 审批后调整 | **自动调整库存** |
| ⑤ 调拨记账 | 一张单双向记账 / 生成一出一入两张单 / 在途处理 | **一张单双向记账** |

默认值都偏规范、偏安全。**如果和你们原来的习惯不一样，直接在参数中心改，不用改代码。**

还支持**分级覆盖**：例如全局禁止负库存，但单独允许某个仓库负库存。

### 程序以托盘方式运行

它**不会在任务栏留命令行窗口**，只在右下角托盘区留一个图标
（找不到就点任务栏的小三角 `^` 展开）。**双击托盘图标 = 打开系统主页。**

托盘右键菜单：

| 菜单项 | 作用 |
|---|---|
| 打开系统主页 | 用默认浏览器打开界面（菜单上会显示当前端口） |
| 启动数据库 / 停止数据库 | 单独控制数据库，菜单第二行实时显示数据库状态 |
| 修改运行端口 … | 改端口号，重启生效 |
| 打开配置文件 / 打开日志目录 | 排障用 |
| 打包备份到 U 盘 … | 生成完整搬家/备份包（约 1.1 GB） |
| 从备份还原 … | 用备份包替换当前数据（旧数据自动改名保留） |
| 设置每日自动备份 … | 注册 Windows 计划任务，每天定时自动打包 |
| 数据库安全加固 … | 把数据库认证从 `trust` 改成密码认证（**联网/多用户前必做**） |
| 退出系统 | 关闭整个系统，数据库一起安全关闭 |

### 修改运行端口

端口默认 `5076`。两种改法：

- **推荐**：右键托盘图标 → **修改运行端口 …**，输入新端口（1024 ~ 65535），
  确定后会弹窗告诉你新的访问地址，按提示退出系统再重新双击 exe。
- 或右键 → 打开配置文件，改 `"Port": 5076,` 这一行，保存后重启生效。

> 端口必须 ≥ 1024；**改完不重启不生效**。

### 换电脑（搬家）

1. 旧电脑：右键托盘图标 →「**打包备份到 U 盘 …**」，选位置，点「开始打包」
2. 把生成的 `YuanErpBackup_日期时间` **整个文件夹**拷到新电脑（**路径不要有中文**）
3. 双击文件夹里的 `Yuan-Erp.exe`

新电脑上**不用装任何东西** —— .NET 运行时、PostgreSQL、你的数据全在包里。

### 备份建议

> **必须放在另一块物理盘**（U 盘 / 移动硬盘 / 网盘）。
> 存在同一块硬盘上等于没备份 —— 硬盘一坏，数据和备份会一起没。
>
> 建议每周做一次手动备份；需要的话用「设置每日自动备份 …」注册计划任务。

### 常见问题

**Q：双击 exe 后没有任何反应？**
程序是托盘方式运行的，本来就不弹窗口。看右下角托盘区（点 `^` 展开）。
托盘里也没有图标说明启动失败 —— 会弹错误框，也可以看 `发布\logs\` 里最新的日志。

**Q：网页提示连不上数据库？**
右键托盘图标看第二行状态：显示「已停止」→ 点「启动数据库」；
显示「运行中」但仍连不上 → 等几秒重试（首次初始化会慢一些）。

**Q：想清空数据重来？**
右键托盘 → 退出系统，双击 `重置数据库.bat`，输入 `YES` 确认。
下次启动会自动重建为全新系统（账号密码不变）。

**Q：电脑突然断电，数据会不会丢？**
不会损坏，已提示「保存成功」的数据一条都不会少。
会丢的只有**没提示保存成功的那几笔**（整笔回滚，不会出现半截数据）。
硬盘物理损坏、误删、病毒、火灾水淹只能靠备份解决 —— 所以备份一定要做，而且要放另一块盘。

**Q：怎么让局域网内其他电脑访问？**
先右键托盘 →「**数据库安全加固 …**」（它会设置随机强密码、把认证改成 `scram-sha-256`、
并自动把新密码写回配置文件，失败会自动回滚），然后放行防火墙端口。
⚠️ 单机使用时不用管它。

## 特技

### 本项目的几个「不太一样」的地方

- **真的是单文件**：`Yuan-Erp.exe` 自带 .NET 运行时 + 前端资源，双击即用，
  目标机器**不需要装任何东西**（数据库程序除外，它需要单独放一次）。
- **零配置开箱**：首次运行自动 `initdb` → 建库 → 建表 → 灌种子数据，全程无人干预。
- **托盘常驻，不占任务栏**：没有黑色命令行窗口，右键菜单里能独立启停数据库、改端口、备份还原。
- **搬家 = 拷文件夹**：整包约 1.1 GB，拷到新电脑双击就能跑，登录态都不受影响。
- **改规则不改代码**：五条核心业务规则全部在界面上配，还支持按仓库/货物分级覆盖。
- **断电不怕**：数据库强制落盘参数全开，已保存的数据不会丢、不会半截。
